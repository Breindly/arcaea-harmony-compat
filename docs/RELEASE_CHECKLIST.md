# Release Checklist

- [ ] `tools/check-open-source-boundary.ps1` passes
- [ ] No APK, HAP, ZIP, native library or crash dump is tracked
- [ ] No official game resource is tracked
- [ ] No personal path, account ID, device ID or signing secret is tracked
- [ ] LICENSE and NOTICE are current
- [ ] README build steps work from a clean checkout
- [ ] Tests use synthetic or user-supplied fixtures only
- [ ] Release archives contain source and documentation only
- [ ] No binary patch intended to bypass licensing or paid content is included
