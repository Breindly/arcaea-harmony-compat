# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-11-24

### Added

- Initial open-source repository boundary
- Apache-2.0 licensing and NOTICE
- AFF parser, playback, judging and rendering source
- HarmonyOS ArkUI and NAPI integration source
- Synthetic parser fixture
- Version Profile schema and examples
- Resource exclusion and release checklists
- Portable build and repository-boundary scripts

### Excluded

- Proprietary game packages and resources
- Native libraries copied from third-party software
- Save data, crash dumps and device-specific identifiers
- Unlock, anti-tamper and licensing bypass logic
